# 个人手机版连续语音对话

## 安装包

[下载本分支 Android APK](https://github.com/wang1733238039/codex-mobile/releases/download/v0.2.0-voice-preview.1/codex-mobile-0.2.0-preview.apk)；
[版本说明与校验文件](https://github.com/wang1733238039/codex-mobile/releases/tag/v0.2.0-voice-preview.1)。

- Android 8.0 及以上，系统识别出的版本为 `0.2.0-dev`，包名 `com.codexmobile.personal.debug`。
- 用手机浏览器下载后打开 APK；系统提示时允许该浏览器安装本次应用。此包为开发签名预览版。
- 安装完成还需连接电脑。现有网页继续可用，安装 App 不会迁移网页登录或电脑配对数据。
- iOS 已完成模拟器编译；iPhone 真机需自己的签名团队和设备授权，本次不提供可直接安装的 IPA。

## 使用

原生 App 使用电脑 Host 连接参数；具体地址、Host ID、证书与密钥必须由自己的电脑配置生成。已有网页版登录账号与服务器地址不会自动转换成原生 Host 连接参数。同一局域网可使用已验证的电脑 HTTPS 地址，外出使用需另有可达的 VPN 或 HTTPS 通道。现有网页版的公网入口继续保留。

本次本机检查在原生 Host 的 Windows PowerShell helper 阶段被 `Restricted` 执行策略拒绝，尚未修改策略、启动原生 Host 或生成可交付的原生连接参数；不能把两个网页连接程序在线写成原生 Host 在线。完成本机策略处理后，再按仓库的 Host 配置流程核对局域网 HTTPS、设备认证和原桌面 owner，外出入口另行配置与验证。没有已验证地址时不要在 App 中填写电脑的 `127.0.0.1` 或把网页域名当成 Host 地址。

连接电脑并打开一个空闲的现有对话，点击输入区电话图标，允许麦克风和系统语音识别。说完后发送，Codex 执行完成后朗读，再继续听下一句。普通麦克风图标仍是可编辑的语音输入。

- 播报时点“打断并说话”继续提问。
- “结束通话”关闭麦克风与播放，电脑已接收的任务继续。
- “停止电脑任务”走原任务停止与轮次校验。
- 原文字草稿保留。通话绑定原电脑和对话，不能把别的对话回复读过来。
- 审批、断连、退后台或未知提交会暂停；不会自动重新发送指令。
- 收到回执但没有确认轮次，或任务结束后没有取得最终文字回复时会暂停，保留原操作记录，不让通话一直卡在等待中。
- 第一版轮流听说，提供按钮打断，不宣称免点击的全双工声学打断。
- 使用系统识别和语音合成，不要求另配模型 Key；是否联网、可用语言与音色取决于手机系统及已安装的语音服务。

## 工程

Android 包身份改为 `com.codexmobile.personal`，开发版带 `.debug`，与上游 App 分开安装，源码仍使用原 namespace。iOS 同样使用独立包身份 `com.codexmobile.personal`，已清除上游签名团队；构建需要 Mac/Xcode，真机还需用户自己的签名团队与设备授权。

`Personal mobile builds` 工作流分别构建 Android APK 与 iOS Simulator App；构建不能代替麦克风、扬声器及桌面真实任务验收。上游README中的APK属于上游，不包含本分支改动。
