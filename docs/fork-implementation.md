## 桌面控制适配

现有服务器账号、设备令牌与主动出站 WebSocket 保持。电脑连接程序新增原桌面 IPC 适配，发现目标会话的实际 owner 后才可发送、补充、停止及审批。电脑私有 IPC 不暴露到公网；网页 API 只开放具名操作，不接收任意方法名。

桌面操作绑定原 threadId、turnId、owner 和操作 ID。没有写入前的拒绝可提示恢复；写入后超时为未知，禁止自动改走 CLI 重发。历史可读、进程存在、连接成功分别展示，不能当作会话可控证明。原 CLI 通道保留给自身已启动任务及没有桌面 owner 的场景。

## 连续语音对话

复用原生系统语音识别和系统语音合成，不要求新增模型 Key，不把 Codex 登录凭据交给手机。系统语音能力可能依赖设备已安装的语言服务或联网，不能承诺全部离线。

通话绑定已选择的电脑、runtime 与现有会话，保留文字草稿。用户主动开始后逐句识别并经原发送链路提交，收到本次输入对应的最终回复后朗读，再听下一句。播报时提供“打断并说话”，仅停止音频；停止电脑任务为独立按钮。第一阶段采用轮流听说，避免扬声器把自身回复识别成新指令。

切换目标、退后台、断连、权限拒绝、提交未知或审批等待时暂停语音。未确认提交不自动重发；恢复必须由用户操作。不能朗读其他会话或开始通话前的历史消息。过长回复有界分段，保留屏幕全文。

## 验收

分别检查桌面协议边界、未知结果不重放、审批归属及原有网页回归；分别编译 Android、iOS 并记录工具链与真机能力。单元测试和构建不替代手机麦克风、扬声器及真实桌面任务的实机验收。当前开发机是 Windows，不能使用上游记录中的 Mac/iPhone 身份冒充当前设备。
